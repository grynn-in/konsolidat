# Documentation lives at docs.konsolidat.com

Decision (Deepak Pai, 2026-11-05, [konsolidat-docs#2](https://github.com/grynn-in/konsolidat-docs/issues/2)): the Docusaurus site in `grynn-in/konsolidat-docs` is the canonical documentation tree. Reader-facing prose (guides, references, API pages, roadmap) is written there and only there. The MkDocs tree that used to live here was removed in the same change.

This folder keeps only **records written in the pull-request flow**, which the docs site copies one way (`scripts/sync-from-repo.sh` in konsolidat-docs) and never edits:

| folder | what | synced to |
|---|---|---|
| `decisions/` | decision records (index + one file per decision), Docusaurus-flavoured markdown with frontmatter | `/developer-guide/decisions/` |
| `prd/` | product requirement documents | linked from the site by GitHub URL, not copied |
| `design/rules.md` | generated by `scripts/extract_assertion_rules.py` from `dbt_project/tests`; do not edit | `/reference/assertion-rules` |

`.github/workflows/docs-guard.yml` fails a push or pull request that adds any other markdown under `docs/`. If you need to document something for readers, open a pull request on konsolidat-docs instead.
